# VeggieGo Customer App

Customer Android application for VeggieGo Pure Veg Food Delivery.

## Features

- OTP Login
- Restaurant Listing
- Search Restaurants
- Search Menu Items
- Live Order Tracking
- COD Payment
- Online Payment
- Notifications
- Order History
- Address Management

## Technology

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Google Maps
